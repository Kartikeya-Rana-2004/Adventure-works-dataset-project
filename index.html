Azure Databricks Medallion Architecture Pipeline

Bronze Layer (Raw Ingestion)

ADLS Gen2 landing zone. Ingests raw CSV and JSON drops with automated schema inference, attaching ingestion timestamp metadata (_ingested_at, _source_file, _batch_id) for immutable lineage tracking.

Silver Layer (SCD Type 2 & Conforming)

Cleansed Delta Lake tables. Eliminates duplicate keys, handles null values, conforms product taxonomies, and tracks historical changes in customer demographic attributes using Slowly Changing Dimension Type 2 (valid_from, valid_to, is_current).

Gold Layer (Star Schema & Marts)

Production Star Schema modeled with dbt. Partitions fct_sales by year and month. Pre-computes dimensional views for executive analytics, customer lifetime value (LTV), and Synapse / Power BI direct queries.
